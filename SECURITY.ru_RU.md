# Безопасность версии 4.3.1

Изменены конкретные места из присланного обзора:

- Вместо меняющегося Docker `latest` используется закреплённый digest образа. Старый тег разрешён только для распознавания и миграции прежней установки. Новый runner отклоняет другой образ в env.
- ConsoleClient загружается из конкретного коммита официального репозитория и проверяется по фиксированному SHA-256 до chmod, Docker build и использования. При несовпадении установщик прекращает работу. Ветка master и динамический поиск исполняемого файла убраны. Обновление console backend тоже проверяет и пересобирает бинарник.
- В Docker build передаются только Dockerfile и проверенный ConsoleClient; приватная конфигурация и база исключены из контекста сборки.
- Образ Debian для console backend закреплён по digest. Для Go-модулей принудительно включён checksum-сервис и сохранён штатный выбор Go toolchain с проверкой checksum. Слишком старый Go отклоняется до остановки служб; существующая установка Go не заменяется. Проверка SHA-256 curl-impersonate сохранена.
- Контейнер Psiphon работает от UID/GID 1000:1000, без Linux capabilities, с корневой файловой системой только для чтения, временным /tmp, ограничением процессов и no-new-privileges. Из образа запускается непосредственно Psiphon, без root-скрипта создания пользователя. Записывать можно в принадлежащую этому UID конфигурацию и базу /config.
- Службы systemd ограничены по файловой системе и capabilities: защита домашней директории, ядра и cgroups, отдельные tmp/devices, ограничения namespaces и приватный umask. Код программы недоступен монитору для записи через эти пути.

**Контроллер на хосте остаётся root.** Он управляет Docker/systemd, конфигурацией и остановкой Psiphon перед чтением BoltDB. Доступ к Docker API эквивалентен root; создание пользователя с группой docker не решает эту проблему. Ограничения systemd снижают риск, но не гарантируют изоляцию полностью скомпрометированного контроллера от хоста. Установщик также требует root для пакетов и служб. Docker socket не передаётся в контейнер Psiphon.

`--bind` сохранён как явный выбор пользователя для обычных режимов. По умолчанию остаётся loopback; публичный адрес запрещён. При выборе частного IP прокси без авторизации доступен тем, кто может подключиться к этому адресу. Для YouTube Mode требуется loopback. Работающий экземпляр Gemini не переводится автоматически в RU.

Все проверки IP и Google GeoIP идут через SOCKS5h соответствующего экземпляра, без прямого запасного подключения. UNKNOWN не считается RU. Серверные записи кэша содержат служебные реквизиты подключения и сохраняются с правами 0600. Не публикуйте их и необработанные Docker-логи Psiphon; в notices могут быть служебные параметры. Для диагностики предпочтителен журнал монитора.

Точные digest, коммит и SHA-256 приведены в [SECURITY.md](SECURITY.md). Они получены 15.11.2026: SHA-256 манифестов сопоставлен с заголовками registry, официальный бинарник из фиксированного коммита скачан и хеширован. Закрепление обеспечивает неизменность содержимого, но не является независимым аудитом стороннего образа на вредоносность. Полная воспроизводимость APT-пакетов не заявляется: они устанавливаются из подписанных Debian-репозиториев.

Обновление из пункта 5 получает установщик собственного проекта по конкретному GitHub-коммиту, сверяет Git blob-хеш с метаданными GitHub и проверяет синтаксис Bash перед подтверждением. SHA-256 показывается для аудита; это не независимая цифровая подпись. Источник ограничен API своего репозитория, файл имеет права 0600 во временном приватном каталоге, понижение версии запрещено. После подтверждения установщик выполняется от root для выбранного экземпляра с сохранением настроек. Обновление доверяет владельцу Forcus356 и GitHub; от компрометации самого аккаунта репозитория оно не защищает. Успешный коммит и хеш сохраняются в update-source.json.
